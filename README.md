# Zumba Burgos · Demo independiente

Propuesta de Agallart Digital. Datos ficticios y sin datos de clientes, teléfonos, precios ni horarios reales del negocio.

Incluye tres apartados:

- Consultas: filtros, creación de ejemplos, edición, cambios de estado y notas.
- Alumnos: búsqueda por nombre o código, ficha individual con historial de clases, asistencia de ejemplo y próximas clases.
- Calendario: vista mensual navegable, clases por día y lista de participantes de cada sesión. Desde cada clase se puede abrir la ficha de sus alumnos y desde cada historial, la clase correspondiente.

Todos los alumnos, grupos, clases, salas, horarios y asistencias son ficticios. El calendario abre en octubre de 2026 para mostrar los ejemplos. Los datos solo viven en memoria y los cambios se reinician al recargar. No envía mensajes, reserva clases ni procesa pagos. No introducir datos personales reales.

Archivo HTML autónomo, sin dependencias externas. Puede abrirse localmente o servirse con GitHub Pages desde la raíz de main.

Las funciones son ideas para validar con el negocio. Identidad y alcance basados en la conversación previa por Instagram; no se afirma que la empresa trabaje actualmente de esta manera.
